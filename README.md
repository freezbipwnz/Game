# 🏰 Теневой Замок

Процедурный средневековый детектив — аналог Murdoku. Каждое дело генерируется заново: поле, герои и улики рождаются с гарантированно единственным решением.

## Правила игры

- **Расставьте подозреваемых**: по одному в каждом зале (строке) и каждой галерее (столбце).
- **Тело жертвы** — в пустой клетке; убийца стоял рядом и был там один.
- **Свидетельства правдивы** — дедуцируйте, проверяйте, обвиняйте.
- **Код дела** делится: одно и то же дело на всех устройствах.

### Уровни сложности

| Уровень | Размер | Описание |
|---------|--------|----------|
| 🛡️ Оруженосец | 5×5 | Прямые свидетельства, обучение дедукции |
| ⚔️ Рыцарь | 6×6 | Больше залов, хитрее слухи |
| 🔥 Инквизитор | 6×6 | Лишь косвенные улики |

## Как запустить

Локально:
